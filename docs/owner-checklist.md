# Что осталось сделать владельцу перед публикацией

Агенты довели сайт до состояния «работает, проверено, ждёт ваших данных». Здесь то, что можете сделать только вы. Основа — Task 7 из `docs/superpowers/plans/2026-11-03-landing-portfolio.md`; ниже она дополнена решениями ревью.

## 1. Данные
- [ ] Заменить все пометки `[ВСТАВИТЬ…]`, `[ПОДТВЕРДИТЬ…]`, `[УТОЧНИТЬ…]`, `[ИМЯ]`. Идите по выводу `node scripts/check.mjs --release` сверху вниз: он называет файл и строку.
- [ ] У трёх кнопок «Открыть» в проектах стоят ссылки-заглушки `href="#"` (`public/index.html`, около строк 199, 214, 229): вписать адреса или убрать кнопки. Релизная проверка их тоже ловит.
- [ ] Кнопка «Написать мне в Telegram» ведёт на `#contact`: заменить `href` и текст на свой аккаунт.
- [ ] Домен: `public/robots.txt`, `public/sitemap.xml`, canonical и og-теги.
- [ ] Итог: `node scripts/check.mjs --release` и `npm test` проходят без ошибок.

## 2. Vercel
- [ ] Add New → Project → импорт репозитория, Framework Preset: Other. Команду сборки не задавать.
- [ ] Settings → General → Node.js Version: 22 или выше (в `package.json` указано `>=22`).
- [ ] Переменные из `.env.example` (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`, `MAIL_TO`) — и для Production, и для Preview. Для Яндекса или Mail.ru нужен пароль приложения: вход с зарубежного адреса иначе может блокироваться.
- [ ] Settings → Domains: добавить домен, прописать DNS, дождаться SSL.

## 3. Боевая проверка
- [ ] Настоящая заявка с сайта приходит и на email, и в Telegram меньше чем за минуту.
- [ ] `curl -i -X POST https://<домен>/api/lead -d "name=T&contact=@t&consent=on&elapsed_ms=5000"` отвечает 200.
- [ ] Внутренние файлы недоступны: `/tz-landing.md`, `/preview.html`, `/package.json`, `/lib/lead/handler.js` дают 404. Несуществующий адрес показывает нашу страницу 404.
- [ ] Lighthouse на боевом адресе не ниже 95. Прогнать ещё раз с видимым баннером cookie (его при замерах не было) и в PageSpeed Insights: чек в первом экране иногда становится самым большим элементом, и отрисовка может выйти за 2 с.

## 4. Аналитика
- [ ] Решить, нужна ли Метрика на старте. Если нет — убрать баннер, `consent.js`, раздел 6 политики и кнопку «Настройки cookie».
- [ ] Если нужна: один и тот же номер в `<meta name="ym-id">` на всех трёх страницах (проверка это требует), опубликовать заново.
- [ ] До «Принять» запросов к `mc.yandex.ru` нет. После «Принять» → «Настройки cookie» → «Отклонить» счётчик перестаёт слать данные (остановка `destruct` проверена только на подставном скрипте, на настоящем счётчике — только вы).
