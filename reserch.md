# Исследование: сайты экспертов по веб-разработке и IT-проектам

**Дата исследования:** 03.11.2026
**Цель:** понять, как устроены сильные сайты экспертов (архитектура, блоки, шрифты, тренды, подходы), чтобы спроектировать сайт о себе как об эксперте по созданию сайтов и других IT-проектов.
**Как проводилось:** три независимых агента с разными ролями (дизайнер, маркетолог, UX/UI-архитектор) изучили одни и те же 5 сайтов. Данные взяты из HTML, CSS, sitemap.xml и текстов страниц.

---

## 1. Главное за одну минуту

1. **Сильные сайты экспертов держатся на одной мысли:** кто вы, для кого и какой результат. Эта мысль стоит в первом экране и подкреплена доказательствами (цифры, клиенты, проекты).
2. **Две рабочие модели.**
   - *Образовательная* (Josh Comeau, Kent C. Dodds): бесплатный контент → рассылка → платные курсы.
   - *Репутационная* (Brittany Chiang, Lee Robinson): сайт нужен для найма и авторитета, прямой монетизации нет.
   - *Maker-модель* (Pieter Levels): публичные проекты и цифры, платный доступ к автору.
3. **Для фриланса и услуг ни один референс не подходит один в один.** У Brittany и Lee почти нет канала связи, у Kent контакт требует аккаунта. Это ваше конкурентное преимущество: хороший контакт, услуги и кейсы на главной.
4. **Отзывов на главной нет ни у одного из пяти.** Сильнее всего работают цифры (аудитория, скачивания, установки) и узнаваемые бренды.
5. **Шрифтовой «характер» почти не зависит от экзотики.** Платные кастомные шрифты только у Josh. У остальных системный стек, Inter или системный serif.
6. **У каждого сайта есть одна запоминающаяся деталь:** анимированная смена темы, маскот, spotlight за курсором, оживающая картина, жёлтый «маркер» выделения.
7. **Тёмная тема стала нормой:** есть у 4 из 5 сайтов (у Brittany сайт только тёмный).
8. **Типичные слабости референсов** (их можно обойти): нет JSON-LD, устаревшие sitemap и данные, пустые alt, тяжёлые шрифты и картинки, отсутствие лид-магнита.

## 3. Профили сайтов

### 3.1 joshwcomeau.com
- **Устройство:** многостраничный блог. Статьи по разделам `/css/…`, `/react/…`, `/animation/…`, глубина 2. Курсы вынесены на отдельные домены.
- **Главная:** hero нет. Лента из 10 статей → категории (8 тегов) → «Popular Content» → футер с подпиской, тремя курсами, поиском, переключателем темы и звуком.
- **Дизайн:** Wotfard (текст), Cartograph CF (код), Sriracha (акцент), все self-hosted. Синий `#4242fa` и розовый `#ff1981`. Тема переключается анимированно.
- **Маркетинг:** 32 024 зарегистрированных студента, ~600 000 скачиваний npm в месяц, логотипы компаний, отзывы известных разработчиков. Три курса, бандл, командные лицензии, региональные цены, возврат 30 дней.
- **Слабые места:** `sitemap.xml` отдаёт 404, нет JSON-LD, на главной нет `<main>`, страница-хаб курсов устарела (сообщает «выйдет в 2026», хотя запись уже открыта).
- **Техника:** Next.js (App Router), Vercel, JS ≈261 КБ.

### 3.2 kentcdodds.com
- **Устройство:** крупная платформа, 618 URL в sitemap (блог 216, `/calls` 236, `/chats` 135). Глубина до 4.
- **Главная:** hero с двумя CTA → видео-интро 2:13 → «Hi, I'm Kent» → табы blog/courses/podcasts → 3 рекомендации блога → 5 курсов → Discord → личный блок → футер с подпиской.
- **Дизайн:** системный sans (предположение: Matter 400 и 500, self-hosted), «командные» цвета (синий `#36a3ff`, красный, жёлтый), маскот Kody, тёмная тема `#1f2028`.
- **Маркетинг:** блог прочитан 966 563 раза 767 660 людьми. Страница `/testimonials` с 56 отзывами и формой отправки. Около 15 CTA на главной. Бесплатный Call Kent: вопрос голосом, ответ выходит подкастом.
- **Слабые места:** бургер-кнопка без `aria-label`, нет skip-ссылки, h1 спрятан в логотипе, `/contact` требует аккаунта, миссия размыта, JSON-LD нет.
- **Техника:** React Router и Tailwind, Cloudflare, Fathom. JS ≈300 КБ.

### 3.3 brittanychiang.com
- **Устройство:** одностраничник плюс `/archive` (таблица всех проектов) и `resume.pdf`. В sitemap 3 URL.
- **Главная:** слева закреплённая колонка (имя, роль, меню-якоря, соцсети), справа About → Experience (6 мест, теги стека) → Projects (4 карточки) → Writing (4 статьи).
- **Дизайн:** Inter, фон `#0f172a`, акцент teal `#5eead4`, только тёмная тема. Spotlight за курсором, при наведении на список остальные элементы тускнеют.
- **Маркетинг:** сайт работает на найм. Работодатели (Klaviyo, Upstatement, Apple), клиенты студии, пресса, 100k+ установок темы Halcyon. Рассылки и лид-магнита нет.
- **Слабые места:** нет email и формы, связь только через соцсети. Sitemap от 2023-05-16. Девять preload-шрифтов (≈1,2 МБ).
- **Сильное место:** доступность, образец для подражания (skip-ссылка, landmarks, `:focus-visible`, `prefers-reduced-motion`).
- **Техника:** Next.js (Pages Router), Tailwind, Vercel. JS ≈183 КБ, CSS ≈6 КБ.

### 3.4 leerob.com
- **Устройство:** минимализм. 68 URL: 22 плоских страницы (`/ai`, `/dx`, `/vercel`…) и 46 страниц словаря `/_glossary/*`.
- **Главная:** один текстовый экран без меню. Ник `@leerob` → биография с переключателем Default/Long → Notes (10 тем) → Blogs (8 эссе) → рисованная картина. Футера нет.
- **Дизайн:** serif Iowan Old Style (системный, есть только на устройствах Apple) → Palatino → Georgia. Caveat для рукописных акцентов. Тёплая тёмная тема `#1b1a19`. Акцентного цвета нет. Рисованная SVG-картина с анимацией (облака, растения).
- **Маркетинг:** только имена работодателей, ни цифр, ни отзывов. Единственный CTA: email для консультаций.
- **Слабые места:** JSON-LD Person устарел (указан Cursor, в видимой биографии SpaceX). HTML весит 800 КБ из-за 213 inline-скриптов.
- **Техника:** Next.js, Vercel. JS ≈202 КБ.

### 3.5 levels.io
- **Устройство:** блог-лента, 20 лет контента. Служебные страницы: `/projects`, `/stats`, `/contact-me`, `/ama`, `/vc`, `/rss`, `/api`, `/mcp`, `/llms.txt`.
- **Главная:** представление и список продуктов → счётчик читателей → подписка (и Telegram) → поиск → закреплённые посты → лента по месяцам → повторная подписка → футер.
- **Дизайн:** системный sans, колонка 42rem (672px), акцент `#16a2f9`, жёлтое выделение текста `#ffef5b`. Почти никакого декора.
- **Маркетинг:** 184 909 читателей рассылки, 6.2B просмотров. `/projects` честно показывает успехи и провалы. Платный созвон от $15 000 за 30 минут, рядом бесплатный ИИ-чат `/ama`: цена работает как фильтр.
- **Слабые места:** самая слабая доступность из пяти (нет `<main>`, у всех 953 картинок пустой `alt`, нет `prefers-reduced-motion`). Тяжёлые обложки (PNG до 1,9 МБ). Часть постов политическая, для сайта, который продаёт услуги, это риск.
- **Техника:** собственный движок LevelsBlog, Cloudflare, Simple Analytics.

### 4.2 Типовые паттерны архитектуры
- Глубина сайта 1–2 уровня (у Kent до 4, но это платформа с тысячами материалов).
- Навигация короткая: 4–9 пунктов. Мобильное меню: бургер или нативный Popover API.
- Платные продукты почти всегда вынесены на отдельные домены или лендинги со своим брендом.
- Блог есть у четырёх из пяти (у Brittany только ссылки на внешние статьи).
- Служебные страницы повторяются: `/about`, `/contact`, `/projects` или `/courses`, `/uses`, `/testimonials`, `/subscribe`, RSS.

### 4.3 Компоненты
Карточки проектов и статей, теги, таймлайн опыта (Brittany), ARIA-табы (Kent), блоки кода с подсветкой, оглавление статьи с якорями (Josh), интерактивные демо, фильтры и сортировка (Levels), переключатель длины биографии (Lee), FAQ на `<details>` (Josh).

## 5. Дизайн

### 5.1 Шрифты

| Сайт | Заголовки и текст | Код | Акцент | Загрузка |
|---|---|---|---|---|
| Josh | Wotfard (400/500/600) | Cartograph CF | Sriracha | self-hosted woff2, `font-display: fallback`, fallback с `size-adjust` |

### 5.2 Типографика
- Базовый размер везде 16–17px, межстрочный интервал 1.5–1.65.
- Узкая колонка текста: 600–672px (Lee, Levels).
- H1 у Brittany 36/48px bold с `tracking-tight`. У Lee `clamp(2.2rem, 3.5vw, 2.65rem)`, вес 600, `letter-spacing -.02em`.
- Мелкие «эйброу»-метки: 14px, UPPERCASE, `tracking-widest` (Brittany, Josh).
- Технические приёмы: `text-wrap: balance` на заголовках, `size-adjust` для fallback-шрифта.

### 5.3 Палитры

| Сайт | Светлая | Тёмная | Акцент |
|---|---|---|---|
| Josh | фон `#fff`, текст `hsl(222 22% 5%)` | фон `#0d0f12`, текст `#e3e6e8` | синий `#4242fa` (тёмная `#809fff`), розовый `#ff1981` |
| Kent | фон `#fff`, вторичный `#f7f7f7` | фон `#1f2028` | командные: синий `#36a3ff`, красный `#ff4545`, жёлтый `#ffd644` |
| Brittany | нет | фон `#0f172a`, текст `#94a3b8`, заголовки `#e2e8f0` | teal `#5eead4` |
| Lee | фон `#fff`, текст `#282828` | тёплый `#1b1a19`, текст `#e8e5df` | нет (цвет только в иллюстрации) |
| Levels | фон `#fff`, текст `#15171a` | фон `#15171a`, текст `#e6e9ec` | `#16a2f9` (тёмная `#3eb0ef`), жёлтое выделение `#ffef5b` |

**Подходы к палитре, которые повторяются:**
1. Тихая нейтральная база и один акцент не более ~10% площади (Brittany, Levels).
2. Тёплые нейтральные без акцента, цвет несут иллюстрация или фото (Lee).
3. CSS-токены (`--color-text`, `--color-primary`) с автосменой темы и плавным transition 300–350 мс (Josh).

### 5.4 Сетка, графика, анимации
- Контейнеры: 1100px (Josh), 1280px (Kent, Brittany), 672px (Levels), до 1500px у Lee с двумя колонками.
- Много «воздуха»: отступы между блоками 64–96px (Josh, Brittany `py-24`).
- Графика: рисованные иллюстрации и маскот вместо стоковых фото. Скриншоты проектов 16:9 с тонкой рамкой (Brittany).
- Анимации: десятки `@keyframes` и View Transitions (Josh), появление hero (Kent), spotlight за курсором (Brittany), оживающая картина (Lee). Везде, кроме Levels, учтён `prefers-reduced-motion`.

### 5.5 Тренды 2026
Источники в основном маркетинговые блоги, поэтому это направление, а не измеренная статистика.

1. **Типографика выходит вперёд:** выразительные variable-serif и книжные засечные, возрождение моно-шрифтов, рукописные «анти-ИИ» акценты. «Чистые нео-гротески» вроде Inter, по этим обзорам, теряют новизну. На практике Lee Robinson уже использует serif плюс Caveat. ([Made Good Designs](https://madegooddesigns.com/font-trends-2026/))
2. **Движение и микроинтерактивность, тёмная тема как норма**, плюс лёгкий код и доступность («sustainable web»). ([Figma](https://www.figma.com/resource-library/web-design-trends/))
3. **«Человечность»:** подлинность и ручная работа вместо одинаковых шаблонов. (по сводке поиска, страницу целиком не открывали: [Barn Images](https://barnimages.com/blog/tips/web-design-trends/))
4. **Для портфолио разработчика:** интерактив, hover-анимации, оптимизация изображений (WebP, AVIF). (по сводке поиска: [Elementor](https://elementor.com/blog/best-web-developer-portfolio-examples/))

**Вывод агента (предположение):** лаконичная типографика плюс один фирменный интерактивный элемент работают лучше, чем 3D-эффекты и яркие градиенты.

Все цифры взяты с самих сайтов и являются самоотчётом авторов.

### 6.2 Общие паттерны
1. Узкое «кто я» одной фразой, подкреплённое брендами (работодатели или свои продукты).
2. Личность выше корпоративности: хобби, истории, шутки (Josh, Brittany, Kent).
3. Бесплатный контент как главный магнит, платное вынесено на отдельные страницы или домены.
4. Рассылка есть у трёх из пяти (Josh, Kent, Levels). У Levels и Josh она встроена почти в каждый экран.
5. Цифры как доверие: прочтения, студенты, подписчики, проекты.
6. Честность: Levels публикует провалы, Josh рассказывает личную историю.
7. Продукт с собственным лендингом и брендом.
8. SEO-минимум одинаковый (title, description, OG). Структурированные данные есть только у leerob.com (Person) и у статей levels.io (BlogPosting). Это пробел, который можно использовать.

### 6.3 Что перенять
- Hero «кто, для кого, что получите» в одну строку и одна главная кнопка.
- Страницу «проекты и результаты» в стиле levels.io с честными статусами.
- Страницу отзывов с именами, должностями и ссылками (Kent).
- Видимые гарантии и условия (Josh): возврат, региональные цены.
- Конкретный следующий шаг в конце каждой статьи.
- Контактную страницу с выбором формата сотрудничества и ценовым фильтром (идея Levels, цены свои).
- Person и Article/BlogPosting JSON-LD.

### 6.4 Чего избегать
- Сайта без канала связи (Brittany): для фриланса это потерянные заявки.
- Размытой миссии без конкретики (Kent, Lee).
- Устаревших данных: JSON-LD (Lee), статус курса (Josh), sitemap (Brittany).
- Десятка равноправных CTA на главной (Kent): внимание рассеивается.
- Резких политических тем, если сайт нужен для клиентов (Levels).
- Отсутствия лид-магнита и рассылки (Brittany, Lee): контакт теряется.

## 8. Рекомендации для вашего сайта

### 8.1 Позиционирование
Один тезис в hero по формуле **«кто + для кого + результат»**. Пример формы (пример, а не готовый текст): «Делаю сайты и IT-проекты, которые приводят клиентов. Для малого бизнеса и экспертов». Две кнопки: основная «Обсудить проект», вторичная «Смотреть работы».

### 8.2 Карта сайта (глубина ≤ 2)
- `/` главная
- `/projects` и `/projects/[slug]` кейсы
- `/services` услуги и процесс работы (с диапазонами цен или сроков)
- `/blog` и `/blog/[slug]` (и `/tags/[tag]`, когда статей станет много)
- `/about` подробный профиль, стек, ссылка на резюме
- `/contact` форма и мессенджеры
- Опционально: `/uses`, `/testimonials`, `/subscribe`
- Служебные: `/privacy`, 404, `rss.xml`, `sitemap.xml`, `robots.txt`

### 8.3 Порядок блоков главной
1. **Шапка:** имя, 4–5 пунктов (Проекты, Услуги, Блог, Обо мне, Контакты), кнопка «Связаться», переключатель темы.
2. **Hero:** тезис, подзаголовок, два CTA, фото.
3. **Полоса доверия:** логотипы клиентов или технологий, 3–4 цифры. Нужен реальный источник цифр.
4. **Избранные проекты:** 3–4 карточки (скриншот, задача, результат, теги стека, ссылка на кейс).
5. **Услуги и процесс:** 3–4 услуги, 4–5 шагов от заявки до запуска.
6. **Обо мне:** короткий текст, фото, ссылка на `/about`, мини-таймлайн по желанию.
7. **Отзывы:** 2–3 цитаты с именем и ролью. Это место, где вы выделитесь: у референсов такого блока на главной нет.
8. **Блог:** 3 лучшие статьи и ссылка «все статьи».
9. **Лид-магнит и подписка:** одно поле email и конкретное обещание (чек-лист «Что подготовить для сайта», шаблон аудита).
10. **FAQ и гарантии:** цены, сроки, правки, поддержка, права на код.
11. **Финальный CTA и контакты:** форма (имя, email, сообщение), email, Telegram, срок ответа.
12. **Футер:** карта сайта, соцсети, политика, копирайт.

### 8.4 Шрифты
Эти пары предложены агентом на основе его знаний, на страницах референсов они не проверялись. **Если сайт будет на русском, проверьте кириллицу в Google Fonts** (у Inter, Manrope, Onest, JetBrains Mono, Caveat она заявлена, остальные проверьте).

1. **Редакционная (доверие и экспертность):** заголовки Source Serif 4 или Literata, текст Inter, код JetBrains Mono.
2. **Чистая технологичная:** заголовки Onest или Manrope (700), текст Inter, код IBM Plex Mono.
3. **С характером:** H1 в Unbounded, текст Inter, код JetBrains Mono, Caveat для коротких рукописных пометок.

Техника для всех: self-hosted variable woff2, `font-display: swap`, fallback с `size-adjust`, `text-wrap: balance` на заголовках, не более 1–2 preload-шрифтов (у Brittany их девять).

### 8.5 Палитра и тема
- Подход «тихая база и один акцент» (slate или тёплый нейтральный + один цвет) проще всего сделать узнаваемым.
- CSS-токены в hsl или oklch, переключатель light / dark / system, плавный transition 300–350 мс.
- Контраст текста не ниже 4.5:1.
- Мелкие фирменные детали стоят копейки (жёлтое выделение текста у Levels).

### 8.6 Фирменная деталь
Выберите одну, не несколько: анимированный логотип или смена темы, spotlight за курсором, оживающая иллюстрация, интерактивный счётчик проектов.

### 8.7 Технический фундамент
- Стек (предположение): Astro или Next.js для статичного сайта-эксперта, у референсов чаще Next.js и Tailwind.
- Mobile-first, `width=device-width, initial-scale=1`, breakpoints около 640 / 768 / 1024, `clamp()` для типографики.
- Картинки AVIF или WebP, `srcset`, lazy для всего, кроме hero.
- Доступность по образцу Brittany: skip-ссылка, один h1, landmarks, alt, `:focus-visible`, `prefers-reduced-motion`.
- SEO: уникальные title и description, OG-картинка, canonical, `lang`, JSON-LD Person и Article, актуальный sitemap.

### 8.8 Как обойти референсы

| Слабость референсов | Как использовать |
|---|---|
| Нет отзывов на главной ни у кого | Блок отзывов сразу после проектов |
| Нет контакта (Brittany, Lee) или нужен аккаунт (Kent) | Простая форма без регистрации + мессенджер |
| JSON-LD почти нет | Person и Article/BlogPosting |
| Нет лид-магнита (Brittany, Lee) | Чек-лист или шаблон за email |
| Пустые alt, нет skip-ссылки | Доступность как конкурентное преимущество |
| Устаревшие данные на сайтах | Регулярно обновляемый sitemap, статусы проектов |

## 9. Ограничения и расхождения

- **Методика.** Агенты скачали HTML и CSS через curl, JavaScript не исполнялся и рендер в браузере не проверялся. Выпадающие меню, динамические цены, всплывающие окна и реальный вид страниц агенты не видели. Размеры шрифтов взяты из CSS, а не из вычисленных стилей.
- **Скорость.** TTFB замерен один раз из одной точки, Lighthouse не запускался.
- **Цифры** (студенты, читатели, просмотры) указаны самими авторами на их сайтах, независимо не проверялись.
- **Шрифт Kent C. Dodds** определён лишь предположительно (Matter 400/500): в отданном CSS у `@font-face` нет `font-family` и `src`, но файлы `Matter-Regular.woff2` и `Matter-Medium.woff2` лежат на сервере.
- **Josh Comeau:** страница `/courses` говорит, что Whimsical Animations выйдет в 2026, а на whimsy.joshwcomeau.com написано, что регистрация открыта. Хаб курсов, похоже, устарел.
- **Lee Robinson:** в JSON-LD указан Cursor, в видимой биографии SpaceX. Внешний поиск переход не подтвердил, поэтому верьте тексту самого сайта с оговоркой.
- **Skip-ссылка у Josh:** цель `#jwc-skip-here` есть, самой ссылки в статическом HTML не нашли (предположение: добавляется на клиенте).
- **Тренды 2026** взяты из маркетинговых блогов, часть по сводке поиска без чтения страницы целиком.
- **Выборка** только англоязычная (см. раздел 2).
- Мобильные меню, sticky-поведение и анимации определены по CSS и разметке, а не наблюдались вживую.
